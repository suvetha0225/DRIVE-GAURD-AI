# DriveGuard AI Frontend

A standalone dashboard prototype for the driver drowsiness project.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

The dashboard currently uses simulated drowsiness values. The next integration step is to connect it to the Python/OpenCV/TensorFlow backend using FastAPI + WebSocket.

## Files
- index.html — dashboard structure
- styles.css — dark safety-monitoring UI
- app.js — navigation, chart, events, demo state
